WOKOV / CULTIVATEC APP - PROYECTO COMPLETO
==========================================

Este zip es el proyecto entero (no un parche). Sirve para subirlo a un repo
nuevo o para abrirlo directo en VS Code.

CÓMO CORRERLO
1. Descomprime. La carpeta de la app es:  cultivatec_flutter/
2. Abre ESA carpeta en VS Code (Archivo > Abrir carpeta).
3. En la terminal de VS Code:
       flutter pub get
       flutter run
   (Si ya habías corrido una versión anterior, detén la app y vuelve a correrla
   desde cero: los assets nuevos NO se cargan con hot reload.)

CÓMO SUBIRLO A UN REPO NUEVO
   cd Cultivatec-app-main
   git init
   git add .
   git commit -m "Wokov app: rediseño azul completo"
   (luego git remote add origin <url> y git push)
   El .gitignore ya excluye build/, .dart_tool/, *.apk y logcat*.txt.

!!! IMPORTANTE: CONTENIDO ACADÉMICO !!!
El archivo  cultivatec_flutter/lib/data/static/stem_content.dart  de este zip es
una copia ANTIGUA del temario (no incluye tus lecciones enriquecidas más nuevas).
ANTES de subirlo al repo, reemplázalo por TU versión más reciente.
Después de reemplazarlo solo hay que revisar 3 cosas en tu versión:
  a) Que la lección 'in_cinematica' use el bloque nuevo (3 tarjetas, 3 preguntas).
  b) Que existan los ids 'in_cinematica', 'in_pid' e 'in_ml' (enlazan a los
     simuladores).
  c) (Opcional, solo estética) en las áreas Chispa y Maker cambia
        color: AppTheme.accentGreen,   ->  color: AppTheme.toneIndigo,
        color: AppTheme.accentOrange,  ->  color: AppTheme.toneAzure,

NOTA: este paquete se revisó con un analizador de sintaxis, pero no se pudo
compilar con el SDK de Flutter. Corre  flutter analyze  y  flutter test  y
repórtame cualquier error.
